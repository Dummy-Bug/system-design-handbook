### Functional Requirements

* Finding the nearby drivers for a rider.
* Show driver's estimated time of arrival.
* Updating driver's location.
* Dynamic Pricing logic.

### Non Functional Requirements

* **Availability** system should be highly available even a fraction of a second downtime is not allowed or else user would move to some other similar app.
* **Scalability** system should be able to handle ever increasing number of riders and drivers.
* **Consistency** system should be strongly consistent like drivers and riders should have consistent view of the area. it should not happen that rider is seeing driver is at some location but actually the driver is somewhere else entirely.
* **Reliabilty** system should provide fast and error free services.
