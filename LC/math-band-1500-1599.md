# Section 1 — Geometry (top topic, 15% of math problems)

## 1.1 Triangle / polygon inequality

**Triangle:** `a + b > c` for all pairs ⇔ valid triangle. Equivalently, `2 × max < a + b + c`.
**Polygon:** sort sides; sum of smaller (n-1) must exceed largest.

**LC problems:**
- *Find Polygon With the Largest Perimeter* (LC 2971, 1521) — sort, prefix sum, find first valid `prefix[i-1] > nums[i]`
- *Largest Triangle Area* (LC 812, 1542) — for each triple, area = `|x1(y2-y3) + x2(y3-y1) + x3(y1-y2)| / 2`

## 1.2 Rectangle / area / packing

**LC problems:**
- *Count Artifacts That Can Be Extracted* (LC 2201, 1525) — check every artifact cell
- *Find All Groups of Farmland* (LC 1992, 1539) — BFS/DFS for rectangle bounds
- *Count Covered Buildings* (LC 3531, 1518) — for each row find min/max x, for each col find min/max y; cell is covered iff strictly inside

## 1.3 Coordinate distance

Manhattan: `|x1-x2| + |y1-y2|`. Two manhattan points are connected at exactly `t` seconds iff `chebyshev <= t` AND `(t - chebyshev) % 2 == 0` (with diagonal moves: `chebyshev = max(|dx|, |dy|)`).

**LC problems:**
- *Determine if a Cell Is Reachable at a Given Time* (LC 2849, 1515) — 8-direction movement → chebyshev distance + parity
- *Matrix Cells in Distance Order* (LC 1030, 1585) — sort by manhattan
- *Watering Plants II* (LC 2105, 1507) — two pointer geometric simulation

## 1.4 Robot / direction

**LC problems:**
- *Robot Bounded In Circle* (LC 1041, 1521) — after 1 instruction cycle, either at origin or direction changed → returns in ≤4 cycles
- *Path Crossing* (LC 1496, 1508) — geometric trail tracking

## 1.5 Surface area / projection

**LC problems:**
- *Surface Area of 3D Shapes* (LC 892, 1507) — `total = 4*sum(grid) - 2*(adjacency overlaps)`. Each tower has 4 vertical sides; each adjacent overlap removes 2.

## 1.6 Right triangles

**LC problems:**
- *Right Triangles* (LC 3128, 1540) — for each pair sharing a row, multiply by (column-count - 1); same for columns

## 1.7 Counting trapezoids

**LC problems:**
- *Count Number of Trapezoids I* (LC 3623, 1579) — group points by y-value; for each pair of distinct y-values, `C(count1, 2) * C(count2, 2)`

## 1.8 Counting unique slopes / horizontal segments

**LC problems:**
- *Maximal Network Rank* (LC 1615, 1521) — degree sum minus shared edge

# Section 7 — XOR (8% of math problems)

## 7.1 Prefix XOR

**Fact:** XOR of subarray `[l..r]` = `prefix[r+1] ^ prefix[l]`. Two prefixes equal iff XOR of range between them is 0.

**LC problems:**
- *Count Triplets That Can Form Two Arrays of Equal XOR* (LC 1442, 1524) — `a ^ b = 0` over `(i..k)` → count prefix equalities
- *Maximum XOR for Each Query* (LC 1829, 1523) — running XOR + maximum trick: XOR with `(1 << maxBit) - 1` to flip all bits

## 7.2 XOR over paths

**LC problems:**
- *Count Paths With the Given XOR Value* (LC 3393, 1573)
- *Neighboring Bitwise XOR* (LC 2683, 1517) — derived array determines original up to choice of original[0]

## 7.3 XOR after operations

**LC problems:**
