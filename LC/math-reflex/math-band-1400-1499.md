**Key empirical findings:**
1. **MOD_ARITH is the #1 math topic at this band** (16% of math problems) — not the rare topic the title-only regex suggested. Reasons: cyclic shifts, divisibility-by-k, parity, "every k-th day" type problems.
2. **PARITY is its own significant category** — 11% of math problems. Not always tagged as MOD_ARITH because the reasoning is structural, not arithmetic.
3. **DIGIT_OPS holds at 12%** — digit manipulation (sum, replace, count, reverse) stays a real skill at this band, not just at 1100-1399.
4. **SUBARRAY_COUNT (streak/contribution) is 11%** — a much larger fraction than at 1100-1399.
5. **PRIME (6%) starts being central** — prime factorization, prime checks.

# Section 1 — Modular arithmetic (the dominant math at this band, 16% of math problems)

## 1.1 Cyclic shifts and rotations

When operations are "shift by k positions" on a structure of size n, the effective shift is `k % n`. The structure returns to itself after `n` shifts (or earlier if there's a smaller period).

**LC problems:**
- *Matrix Similarity After Cyclic Shifts* (LC 2946, 1405)
- *Most Visited Sector in a Circular Track* (LC 1560, 1443)
- *Defuse the Bomb* (LC 1652, 1416) — circular sliding window

## 1.2 Cyclic letters / mod-26

For "next letter cyclically" operations: `next = ((c - 'a' + 1) % 26 + 'a')`. For "shift by k": `(c - 'a' + k) % 26`.

**LC problems:**
- *Make String a Subsequence Using Cyclic Increments* (LC 2825, 1414)
- *Minimum Operations to Transform String* (LC 3675, 1414)

## 1.3 Divisibility checks

Common pattern: "count subarrays with sum divisible by k" → prefix sum mod k, use frequency map of mod classes.

**LC problems:**
- *Count Islands With Total Value Divisible by K* (LC 3619, 1461)
- *Minimum Operations to Make Array Sum Divisible by K* (LC 3512, 1228 — Band 1300 entry)

## 1.4 Mod result (output mod 10^9 + 7)

When problem says "return answer mod 10^9+7", apply mod at every multiplication/addition. Otherwise long can still overflow.

**LC problems:**
- *Range Sum of Sorted Subarray Sums* (LC 1508, 1402)
- *Find the Minimum Possible Sum of a Beautiful Array* (LC 2834, 1409)
- *Count Number of Homogenous Substrings* (LC 1759, 1490) — also uses streak counting

## 1.5 Number of Full Rounds pattern

When time is divided into fixed-length blocks (15 minutes, hour, day), count full blocks via floor division and align endpoints to block boundaries.

**LC problems:**
- *Number of Full Rounds You Have Played* (LC 1904, 1498)

# Section 2 — Parity reasoning (11% of math problems)

## 2.1 Parity as invariant

If an operation preserves parity of some quantity, parity is an invariant. Use it to prove reachability or impossibility.

**LC problems:**
- *Min Cost to Move Chips* (LC 1217, 1407) — moves of ±2 preserve position parity
- *Transform Array to All Equal Elements* (LC 3576, 1489) — count of -1s mod 2 must match
- *Construct Uniform Parity Array II* (LC 3876, 1443)

## 2.2 Parity-based counting

Count items in even and odd index positions separately. Sometimes one side determines the answer.

**LC problems:**
- *Longest Even Odd Subarray With Threshold* (LC 2760, 1420)
- *Even Odd Tree* (LC 1609, 1438) — parity-based level constraints
- *Longest Balanced Subarray I* (LC 3719, 1467)
- *Check if Strings Can be Made Equal With Operations II* (LC 2840, 1486) — even/odd index permutation

## 2.3 Game theory + parity

In games where turn-taking matters, parity of moves often decides the winner.

**LC problems:**
- *Divisor Game* (LC 1025, 1435) — Alice wins iff n is even
- *Vowels Game in a String* (LC 3227, 1451) — Alice wins iff vowel count > 0

# Section 3 — Digit operations (12% of math problems)

## 3.1 Digit decomposition and re-mapping

Standard idioms: extract digits via `n % 10` / `n /= 10`. Build int from digits via `n*10 + d`.

**LC problems:**
- *Subtract Product and Sum of Digits* (LC 1281, 1141 — Band 1100 entry, repeated reflex)
- *Max Difference You Can Get From Changing an Integer* (LC 1432, 1426) — digit replace
- *Largest Number After Mutating Substring* (LC 1946, 1445) — digit replace
- *Sort the Jumbled Numbers* (LC 2191, 1496) — digit remap

## 3.2 Digit constraints / DFS on digits

When the problem says "find all n-digit numbers with property P", DFS where each level picks a digit.

**LC problems:**
- *Numbers With Same Consecutive Differences* (LC 967, 1432)
- *Number of Valid Clock Times* (LC 2437, 1426)
- *Largest Time for Given Digits* (LC 949, 1495)
- *Finding 3-Digit Even Numbers* (LC 2094, 1454)

## 3.3 Digit-based properties

- Sum of factorials of digits (Digitorial Permutation, LC 3848)
- Peaks/valleys of digits (Total Waviness, LC 3751)

# Section 4 — Subarray counting via streak / contribution (11% of math problems)

## 4.1 Streak counting (the n(n+1)/2 reflex)

For each maximal run of length L satisfying a property, contribute `L(L+1)/2` substrings.

**LC problems:**
- *Count Number of Homogenous Substrings* (LC 1759, 1490)
- *Number of Smooth Descent Periods of a Stock* (LC 2110, 1408)
- *Count Alternating Subarrays* (LC 3101, 1404)

## 4.2 Contribution technique

For "sum of X over all subarrays", flip to "for each element, sum its contribution across subarrays".

**LC problems:**
- *Sum of All Odd Length Subarrays* (LC 1588, 1408)
- *Sum of Absolute Differences in a Sorted Array* (LC 1685, 1495)

**Reference:** Full worked example in `reasoning-primitives/04-contribution-technique.md`.

## 4.3 Subarray sum counting

Beyond contribution: count subarrays whose sum satisfies a predicate. Often via prefix sum + hashmap.

**LC problems:**
- *Count Subarrays With Majority Element I* (LC 3737, 1422)
- *Count Beautiful Substrings I* (LC 2947, 1450) — also uses MOD_ARITH
- *Equal Sum Grid Partition I* (LC 3546, 1411)

# Section 5 — Geometry (9% of math problems)

## 5.1 Triangle inequality and angles

**Triangle inequality:** for sides a, b, c, valid triangle iff `a + b > c`, `a + c > b`, `b + c > a`. Equivalently, `2 * max(a,b,c) < a + b + c`.
**Law of cosines:** `cos(A) = (b² + c² - a²) / (2bc)` — gives angle opposite side a.

**LC problems:**
- *Angles of a Triangle* (LC 3899, 1407)
- *Type of Triangle* (LC 3024, 1134 — Band 1100 entry)

## 5.2 Rectangle overlap

Two axis-aligned rectangles overlap iff one is NOT strictly left/right/above/below the other. Easier: NOT overlap iff `rec1[2] <= rec2[0] OR rec2[2] <= rec1[0] OR rec1[3] <= rec2[1] OR rec2[3] <= rec1[1]`.

**LC problems:**
- *Rectangle Overlap* (LC 836, 1442)

## 5.3 Coordinate distance

Manhattan distance: `|x1 - x2| + |y1 - y2|`. Euclidean: `sqrt((x1-x2)² + (y1-y2)²)`. Squared distance (no sqrt) for comparisons.

**LC problems:**
- *K-th Nearest Obstacle Queries* (LC 3275, 1419)
- *Widest Vertical Area Between Two Points* (LC 1637, 1486) — just sort x's, find max gap
- *Projection Area of 3D Shapes* (LC 883, 1425)

## 5.4 Geometric covering

**LC problems:**
- *Minimum Rectangles to Cover Points* (LC 3111, 1401)
- *Maximum Area of a Piece of Cake After Cuts* (LC 1465, 1465) — max horizontal gap × max vertical gap

# Section 8 — Bit operations (7% of math problems)

## 8.1 Binary representation reasoning

Backwards halving for "reach target": if target is even halve (one ×2 step backwards), if odd subtract 1 (one +1 step backwards). Answer = (bit count - 1) increments + (log2 target) doubles, with budget constraints.

**LC problems:**
- *Minimum Moves to Reach Target Score* (LC 2139, 1417)
- *Find Kth Bit in Nth Binary String* (LC 1545, 1479) — recursive bit construction

## 8.2 Bitwise AND/OR/XOR on arrays

Maximum bitwise AND of a subarray = maximum element (taking just that element is optimal).

**LC problems:**
- *Longest Subarray With Maximum Bitwise AND* (LC 2419, 1495)
- *Sum of Root To Leaf Binary Numbers* (LC 1022, 1462) — binary number from tree path
- *Min Ops Binary Array Equal to One II* (LC 3192, 1432) — count of transitions

## 8.3 Bitmask for parity tracking

**LC problems:**
- *Pseudo-Palindromic Paths in a Binary Tree* (LC 1457, 1405) — bitmask digit parities

# Section 9 — Prime factorization (6% of math problems)

## 9.1 Trial division O(√n) — central skill now

```
for (int p = 2; p * p <= n; p++) {
    while (n % p == 0) { add p; n /= p; }
}
if (n > 1) add n;  // n itself is prime
```

**LC problems:**
- *Distinct Prime Factors of Product of Array* (LC 2521, 1413)
- *Smallest Value After Replacing With Sum of Prime Factors* (LC 2507, 1499)
- *Sum of Largest Prime Substrings* (LC 3556, 1439)
- *Min Ops Transform Array into Alternating Prime* (LC 3896, 1435)
- *Prime Arrangements* (LC 1175, 1489) — count primes via sieve

## 9.2 Primality check

For one number: trial division up to √n.
For many queries up to N: sieve.

# Section 10 — GCD / LCM (5% of math problems)

## 10.1 GCD of array

Reduce one at a time: `gcd(arr[0], arr[1], ..., arr[n-1])`.

**LC problems:**
- *Sum of GCD of Formed Pairs* (LC 3867, 1406)
- *Maximum Subarray With Equal Products* (LC 3411, 1443) — `prod = lcm * gcd` invariant

## 10.2 Divisor count from factorization

`n = p1^e1 × p2^e2 × ... × pk^ek` → divisor count = `(e1+1)(e2+1)...(ek+1)`.

**LC problems:**
- *Four Divisors* (LC 1390, 1478)
