# Daily / Weekly Timetable

Locked Apr 2026. Optimized for 1-year DSA grind + LeetDezine + AI work at startup.

## Universal rules (every day, no exceptions)

- **Wake: 7:30 AM**
- **Sleep: 12:00 AM**
- **Morning movement: 20 min** (workout on weekdays, walk on Sat/Sun if preferred)
- **Nap cutoff: 4:00 PM** — past this, no horizontal sleep, ever
- **Evening nap (post-office): 20 min hard cap**
- Consistency > optimization. Same skeleton every day, only the *content* of the LC slot changes.

## Burnout switch signals (Plan B → drop content batching)

If any of these hit, switch Sunday batch to Saturday and make Sunday afternoon rest:

- Skipped Sunday LC contest 2 weeks in a row
- Skipped morning LC 3 weekdays in a single week
- Sleep dropped below 6.5 hrs average for a week
- Snapping at fiancée / family more than usual

If none hit by month 4, current shape is sustainable.

### Zerotrac difficulty progression

Always tag 50-100 below current contest rating. Gap = derivation room.

| Month | Zerotrac filter |
|-------|-----------------|
| 1 (May) | 1450-1500 |
| 2 (Jun) | 1450-1550 |
| 3 (Jul) | 1500-1600 |
| 4-5 (Aug-Sep) | 1550-1650 |
| 6+ (Oct+) | 1600-1700 |

**Pool separation (avoid overlap with virtual contests):**
- Zerotrac: sort by ID descending (newest first), pick from last ~6 months of contests
- Virtual contest pool: contests **12+ months old only** (start ~Weekly #420 backward, walk back one per Wed)
- 6-month gap between pools = clean signal, no accidental recall

**If you spot a zerotrac problem during virtual contest:** mark skipped, treat as 3-problem contest. Honest data > inflated rating.

### Per-problem protocol (90 min morning slot)

| Time | Block |
|------|-------|
| 8:00-8:05 | **Re-solve day-7 problem cold from blank file** (no notes, no editorial) |
| 8:05-8:35 | New zerotrac problem (30 min cap) — paper-first: pattern → approach → code → run |
| 8:35-8:50 | If failed at 30: write 3 lines (pattern guessed, where stuck, missing insight), then editorial |
| 8:50-9:20 | **Cold re-solve of TODAY's new problem** from blank file (locks the pattern) |
| 9:20-9:30 | Log results in `zerotrac-log.md` |

**1 medium done deeply > 3 mediums done shallow.** No volume padding.

Day 1-7: no re-solve slot yet (warm-up phase). From Day 8: re-solve check baked in every session.

### Graduation rule — when to bump rating range

Track every problem in `zerotrac-log.md`. Look at **rolling last 10** problems in current range:

| Metric | Pass threshold |
|--------|----------------|
| AC within 30 min, no editorial | ≥ 7/10 |
| Re-solved cold day+7 (first try, blank file) | ≥ 7/10 |

**Both must independently hit ≥7.** Sum doesn't count.

| 30-min AC | Day+7 re-solve | Action |
|-----------|----------------|--------|
| ≥7/10 | ≥7/10 | **Bump range +50** |
| ≥7/10 | <7/10 | Stay. Session memory ≠ skill. Force more re-solves. |
| <7/10 | ≥7/10 | Stay. Picking too-hard outliers. |
| <7/10 | <7/10 | Stay. Cheat reflex active. Fix protocol, not range. |

Realistic: each range takes 4-8 weeks. The TT.md monthly progression is optimistic.

### Pre/post home visit protocol (Nov)

**Week before:** close upsolve backlog. Pre-batch 2 weeks of LeetDezine content. Don't start a new pattern.

**At home:** fully off. No "1 problem before bed" creep.

**First 3 days back:**
- Day 1: easy zerotrac (1300-1400) — shake rust
- Day 2: one medium, no time pressure
- Day 3: back to normal timed
- Skip Wed virtual in week 1. Resume week 2.

## Hard floors (don't negotiate with yourself)

1. **12:00 AM lights out** — no Twitter scroll, no "just one more" debugging
2. **8:00 AM at desk for LC** — even half-asleep, even bad night
3. **Sunday contest** — show up even if you slept 5 hours
4. **Saturday is sacred** — no productivity creep into it

The chain breaks one slot at a time. Protect the floor, the rest follows.
