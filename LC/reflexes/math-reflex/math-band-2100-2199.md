## PRIME — 6 problems

The biggest story of this band. Prime factorization is now a first-class tool, not just a step in a larger algorithm.

| Problem | Rating | Angle |
|---------|--------|-------|
| [Preimage Size of Factorial Zeroes Function](https://leetcode.com/problems/preimage-size-of-factorial-zeroes-function/) | 2100 | trailing zeros = Σ floor(n/5^k) — binary search, answer is always 0 or 5 |
| [Maximum Partition Factor](https://leetcode.com/problems/maximum-partition-factor/) | 2135 | prime factorize n — any factorization into ≥2 parts multiplies by (p−1) factors |
| [Minimum Jumps to Reach End via Prime Teleportation](https://leetcode.com/problems/minimum-jumps-to-reach-end-via-prime-teleportation/) | 2139 | sieve all primes up to max(arr); group elements by shared prime factor — BFS on prime groups |
| [K-th Smallest Prime Fraction](https://leetcode.com/problems/k-th-smallest-prime-fraction/) | 2169 | binary search on value x: count fractions p/q < x using two-pointer per row |
| [Greatest Common Divisor Traversal](https://leetcode.com/problems/greatest-common-divisor-traversal/) | 2172 | union-find where two numbers connect if GCD > 1; factorize each number, union via shared prime |
| [Digit Operations to Make Two Integers Equal](https://leetcode.com/problems/digit-operations-to-make-two-integers-equal/) | 2186 | BFS on integer transformations — each step must land on a non-prime (primes are blocked) |

**793 (Preimage Size of Factorial Zeroes)** has a beautiful closed-form insight: `f(n) = trailing_zeros(n!) = n/5 + n/25 + n/125 + ...`. This function is non-decreasing and jumps by exactly 1 at most multiples of 5. But at multiples of 25, 125, etc., it jumps by ≥2, so those k values are skipped. The answer is either 0 (k is skipped) or 5 (exactly 5 consecutive integers produce k trailing zeros, since you pass through exactly one multiple of 5 per block of 5). Binary search for the leftmost n where f(n) = k; if f(n) ≠ k, return 0, else return 5.

**2709 (GCD Traversal):** Can all elements be reached from any starting element? Two numbers are connected if GCD > 1. Factorize each number (sieve up to max value), then union-find: each number unions with all its prime factors. Check if the entire array is in one connected component. The sieve + factorize step is O(n log log max_val) — the prime factorization approach is what makes this O(n log n) instead of O(n²).

**3629 (Prime Teleportation):** For each element, compute all its prime factors. Group elements by shared prime. BFS: from any element, you can teleport to any other element in the same prime group in one jump. The graph is on prime-groups, not elements — this collapses a potentially huge graph into a tractable one.

| [Building Boxes](https://leetcode.com/problems/building-boxes/) | 2198 | triangular layers: layer k has T(k) = k(k+1)/2 boxes; find how many full layers fit, then binary search for the remainder |

**1739 (Building Boxes)** is the clearest AP_SUM problem in this band. The maximum boxes fitting in a 3D corner staircase structure: layer k contributes k(k+1)/2 boxes (triangular number). Total for layers 1..m = sum of T(1)+...+T(m) = m(m+1)(m+2)/6 (tetrahedral number). Find m such that this sum just exceeds n, then the remainder sits on the face of layer m+1. Count how many ground-floor positions cover the remainder via another triangle formula.

**1036 (Escape Large Maze):** The key geometric bound: with at most 200 blocked cells, they can enclose at most 200 × 200 / 2 ≈ 20,000 cells (a triangle is the maximum-perimeter-to-area shape for a chain of cells). Run BFS from source capped at 20,001 steps. If BFS reaches the target or exceeds the cap without enclosure, you can escape.

| Problem | Rating | Angle |

| [Minimum Cost Walk in Weighted Graph](https://leetcode.com/problems/minimum-cost-walk-in-weighted-graph/) | 2109 | AND of all edges in a connected component = min cost walk (AND only decreases) |
| [Maximum XOR Product](https://leetcode.com/problems/maximum-xor-product/) | 2128 | greedily assign free bits: for each bit, pick the assignment that maximises both a and b |
| [Minimum Operations to Make the Integer Zero](https://leetcode.com/problems/minimum-operations-to-make-the-integer-zero/) | 2132 | try each op count i from 1 to 40: check if popcount(n − i·k) ≤ i |
| [Bitwise ORs of Subarrays](https://leetcode.com/problems/bitwise-ors-of-subarrays/) | 2133 | at most 32 distinct OR values ending at each position — track previous OR set |
| [Find Subarray With Bitwise AND Closest to K](https://leetcode.com/problems/find-subarray-with-bitwise-and-closest-to-k/) | 2163 | AND is monotone non-increasing as subarray grows — at most 32 distinct values per endpoint |

**3108 (Min Cost Walk):** The insight is that AND of a path can only decrease or stay the same as you add edges. So the minimum-cost walk between two connected nodes is the AND of ALL edges in their connected component (you can always traverse every edge). Build connected components via union-find, AND all edges within each component.

**2749 (Min Ops Make Integer Zero):** You want n = i·k + (n − i·k) where you subtract i powers of 2. So you need popcount(n − i·k) ≤ i (you need i bits to set to subtract them). Try i from 1 to 40 (since 2^40 > 10^12, and after 40 operations any positive number is reachable). For each i, check if n − i·k ≥ 0 and popcount(n − i·k) ≤ i.

## CONTRIBUTION — 4 problems

Three of these are LC classics that appear in nearly every high-level study plan.

| Problem | Rating | Contribution Type |
|---------|--------|------------------|
| [Smallest Rotation with Highest Score](https://leetcode.com/problems/smallest-rotation-with-highest-score/) | 2130 | for each element, compute which rotations give it a score — difference array |
| [Sum of Floored Pairs](https://leetcode.com/problems/sum-of-floored-pairs/) | 2170 | harmonic trick: for each a[j], elements in [v·a[j], (v+1)·a[j]) contribute v to the sum |
| [Sum of Subsequence Widths](https://leetcode.com/problems/sum-of-subsequence-widths/) | 2183 | sort; element i contributes nums[i]·(2^i − 2^(n−1−i)) across all subsequences it's the max vs min |
| [Sum of Distances in Tree](https://leetcode.com/problems/sum-of-distances-in-tree/) | 2197 | rerooting: dist[v] = dist[parent] + (n − 2·subtree_size[v]) |

**891 (Sum of Subsequence Widths):** Sort the array. For each element at position i (0-indexed), it's the maximum in 2^i subsequences (any subset of the i elements to its left) and the minimum in 2^(n−1−i) subsequences (any subset of the n−1−i elements to its right). Net contribution = `A[i] × (2^i − 2^(n−1−i))`. Sum over all i — the total is the answer. The sign alternates because elements on the left increase the max contribution and elements on the right decrease it.

**834 (Sum of Distances in Tree):** Two-pass tree DP. First DFS: compute subtree sizes and dist[0] (sum of distances from root to all nodes). Second DFS (rerooting): when you move the root from parent to child v, all nodes in v's subtree get 1 closer, all other nodes get 1 farther. So `dist[v] = dist[parent] − subtree_size[v] + (n − subtree_size[v])`.

**1862 (Sum of Floored Pairs):** For each pair (i,j), sum floor(a[i]/a[j]). Naive O(n²) is too slow. Instead: for each possible quotient v (from 1 to max_val), count pairs where a[i] is in [v·a[j], (v+1)·a[j]−1]. Using a frequency array with prefix sums, this runs in O(max_val · log(max_val)) via the harmonic sum bound.

| Problem | Rating | The Trick |
|---------|--------|-----------|
| [Equal Rational Numbers](https://leetcode.com/problems/equal-rational-numbers/) | 2121 | convert repeating decimal to exact fraction (non-repeating + repeating/999...9), compare fractions |
| [Minimum Operations to Make the Integer Zero](https://leetcode.com/problems/minimum-operations-to-make-the-integer-zero/) | 2132 | brute-force i from 1..40: check if popcount(n − i·k) ≤ i |
| [Smallest Range II](https://leetcode.com/problems/smallest-range-ii/) | 2135 | sort; try every split — left side gets +k, right side gets −k; formula for max−min at each split |
| [Recover the Original Array](https://leetcode.com/problems/recover-the-original-array/) | 2159 | enumerate possible d (difference): d = (a[1] − a[0]) / 2 for all a[1]; verify feasibility |

**910 (Smallest Range II):** Sort A. Without loss of generality, there's always an optimal split where elements A[0..i] get +k and A[i+1..n-1] get −k. After the operation: new minimum = min(A[0]+k, A[i+1]−k), new maximum = max(A[i]+k, A[n-1]−k). Try all n splits in O(n).

**972 (Equal Rational Numbers):** A repeating decimal like 0.1(6) (meaning 0.1666...) = 0.1 + 0.0(6) = 1/10 + 6/90 = 1/10 + 1/15 = 1/6. The repeating part x.(abc) = x + abc/999. Convert both to exact fractions via Python's `fractions.Fraction` or manual GCD, then compare.

## STARS_BARS — 2 problems

| Problem | Rating | Angle |
|---------|--------|-------|
| [Count Non Decreasing Arrays With Given Digit Sums](https://leetcode.com/problems/count-non-decreasing-arrays-with-given-digit-sums/) | 2172 | distribute fixed total across k positions with constraints — stars and bars + DP |

## Drill plan for this band

**Priority 1 — highest ROI for 1700+ target:**
- **CONTRIBUTION cluster (834, 891, 1862):** all three are LC interview staples. 834 (rerooting) and 891 (sorted contribution) should be derivable cold within 30 min each

- **1621 (K segments stars-and-bars):** understand the bijection that gives C(n+k-1, 2k)
- **1739 (building boxes):** triangular layer formula, binary search on partial layer
