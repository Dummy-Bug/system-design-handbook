**1866 (Rearrange Sticks K Visible):** This is the unsigned Stirling number of the first kind: `S(n, k)` = number of permutations of n elements with exactly k cycles. The recurrence is `S(n,k) = S(n−1,k−1) + (n−1)·S(n−1,k)`. When arranged in a line, sticks visible = cycles in the permutation (each cycle's maximum is visible). Precompute mod 1e9+7.

**3405 (Arrays with K Matching Adjacent):** Count arrays of length n from alphabet m where exactly k adjacent pairs match. Fix which k positions match: C(n−1, k) ways. The first element has m choices. Each non-matching position has (m−1) choices. The k matching positions are forced. Total = C(n−1, k) × m × (m−1)^(n−k−1).

**3116 (Kth Smallest Amount):** Binary search on answer X. Count how many numbers ≤ X are multiples of at least one coin denomination. Use inclusion-exclusion over all 2^n subsets of denominations, where the intersection contribution uses LCM of the subset. LCM can overflow — cap at X+1.

**Standard digit DP template (applies to all 8):**
```
solve(limit) = count valid integers in [1, limit]
answer = solve(R) - solve(L-1)

dp(pos, tight, state):
  if pos == len: return 1 if valid(state) else 0
  max_digit = limit[pos] if tight else 9
  for d in 0..max_digit:
    dp(pos+1, tight and d==max_digit, next_state(state, d))
```
State differs per problem: running sum, running mod, last digit, parity counts, or bitmask of digits seen.

| Problem | Rating | Angle |
|---------|--------|-------|

| [Maximum Strong Pair XOR II](https://leetcode.com/problems/maximum-strong-pair-xor-ii/) | 2349 | sliding window trie: maintain XOR trie of valid elements |
| [Maximum XOR With an Element From Array](https://leetcode.com/problems/maximum-xor-with-an-element-from-array/) | 2359 | offline: sort queries and array by value; process queries in order, add elements to trie as they become valid |
| [Minimum Score After Removals on a Tree](https://leetcode.com/problems/minimum-score-after-removals-on-a-tree/) | 2392 | for each pair of removed edges, the three subtree XORs = total XOR, XOR of one subtree, XOR of other |

**Linear basis (XOR Gaussian elimination):** Maintain a basis of at most 30 vectors (for 30-bit numbers). For each new number, reduce it by XOR-ing with basis elements from highest bit down. If it reduces to 0, it's linearly dependent (already representable). Otherwise insert it. To maximise XOR of any subset, greedily pick each basis element if it increases the current maximum. This O(n·30) structure covers 3845, and the trie variant covers 2935 and 1707.

**810 (Chalkboard XOR Game):** Current player wins if current XOR = 0 (remove any element, opponent faces non-zero) OR number of elements is even (pigeonhole: if n is even and XOR ≠ 0, current player can always find an element to remove that keeps XOR ≠ 0 for the next non-zero state). Answer: win iff XOR = 0 OR n is even.

Recurrence: when adding stick n to a permutation of [n−1], either it becomes visible (place at front of any existing cycle → k cycles becomes k−1 → multiplied by 1) or not (place after any of the n−1 elements → multiplied by n−1). **1755 (Closest Subsequence Sum):** n ≤ 40. Split into two halves of 20 each. Enumerate all 2^20 ≈ 1M subset sums for each half. Sort one half. For each sum in the other half, binary search for the closest complement in `target − sum`. Min absolute difference over all combinations is the answer.

**887 (Super Egg Drop):** The standard "t trials, k eggs" DP is O(kn²). The key reframe: instead of "max floors with t trials", think "with t trials and k eggs, what's the maximum number of floors I can check?" Answer = Σᵢ₌₁ᵏ C(t,i). This is because each trial either breaks (recursing with k−1 eggs, t−1 trials) or doesn't (k eggs, t−1 trials), and the formula follows from Pascal's triangle. Binary search on t until Σᵢ₌₁ᵏ C(t,i) ≥ n.

## Drill plan for this band

**Priority 1 — XOR linear basis:**
- **3845 / 2935 / 1707** — three XOR problems requiring the same linear basis (Gaussian elimination). Implement the basis once, apply to all three. This is the single highest-leverage new skill in this band.

**Priority 2 — Digit DP consolidation:**
- The 8 DIGIT_OPS problems share one template. Derive the template from 2719 (digit sum in range) — it's the cleanest version. Then apply to 2827 (+ divisibility mod), 2999 (+ fixed suffix), 2801 (+ stepping constraint).

**Priority 3 — combinatorics identities:**
- **1866 (Stirling numbers):** Recurrence S(n,k) = S(n−1,k−1) + (n−1)·S(n−1,k). The connection to visible sticks (left-to-right maxima = cycles) is the unlock.
- **887 (Super Egg Drop reframe):** The Σ C(t,i) formula is worth internalising — it converts an opaque DP into a clean binary search.

**Priority 4 — meet in the middle:**
- **1755 (Closest Subsequence Sum)** — classic n=40, split into two halves of 20. Enumerate 2^20 ≈ 1M sums each, sort one, binary search. This pattern reappears every few contests.

**Skip for 1700 target:** 810 (chalkboard XOR — pure game theory, rare), 808 / 837 (probability DP — appears ≤ 1× per 6 months), 1617 (2^15 subset enumeration — brute force, not a reflex).
