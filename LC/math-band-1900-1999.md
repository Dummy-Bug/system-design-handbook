## Band profile

This is where math stops being a side-skill and becomes a primary differentiator. Almost half the band is math. MOD_ARITH is dominant (11 problems) but the real story is **AP_SUM re-emerging strongly** (5 problems — often disguised as binary search) and **BIT_OPS / BITMASK consolidating** into a recognisable cluster. PALINDROME appears in 5 forms from chunked decomposition to prime restriction. The first CATALAN number problem appears here.

New in this band: **CATALAN** (handshakes), **PAIR_COUNT** (image overlap via offset encoding). GCD_LCM deepens from simple GCD checks to Bézout identity and Möbius/inclusion-exclusion.

| [Maximum Value at a Given Index in a Bounded Array](https://leetcode.com/problems/maximum-value-at-a-given-index-in-a-bounded-array/) | 1929 | binary search on value; check: sum = v + (v−1)v/2 + ... uses triangle number formula |

**Key insight for 805 (Split Array Same Average):** before any DP, check if it's even possible. If `total * k % n != 0`, return false immediately. The target sum for a subset of size k is `total * k / n` — only reachable if that's an integer.

## PALINDROME — 5 problems

A dense cluster. Palindrome problems at 1900+ are no longer about basic checks — they require palindrome structure for DP transitions or constrain valid ranges.

| Problem | Rating | Angle |
|---------|--------|-------|
| [Longest Chunked Palindrome Decomposition](https://leetcode.com/problems/longest-chunked-palindrome-decomposition/) | 1912 | greedy from both ends — match prefix=suffix, recurse |
| [Palindrome Partitioning IV](https://leetcode.com/problems/palindrome-partitioning-iv/) | 1925 | check if string can split into 3 palindromes — precompute palindrome DP |
| [Prime Palindrome](https://leetcode.com/problems/prime-palindrome/) | 1938 | all even-digit-length palindromes are divisible by 11 → only odd-digit palindromes can be prime |
| [Palindrome Partitioning III](https://leetcode.com/problems/palindrome-partitioning-iii/) | 1979 | min cost to partition into k palindromes — DP + cost(i,j) precomputed |
| [Longest Almost-Palindromic Substring](https://leetcode.com/problems/longest-almost-palindromic-substring/) | 1990 | palindrome extension with one allowed mismatch |

**Key insight for 866 (Prime Palindrome):** any even-length palindrome like `abba` equals `a×1001 + b×110` = `11 × (...)` so it's always divisible by 11. Only odd-length palindromes can be prime (exception: 11 itself). This immediately prunes the search space.

## TRICK — 5 problems

These require a non-obvious reframe before any algorithm can work.

| Problem | Rating | Angle |
|---------|--------|-------|
| [Longest Well-Performing Interval](https://leetcode.com/problems/longest-well-performing-interval/) | 1908 | convert >8h → +1, ≤8h → −1; find longest prefix sum > 0 |
| [Broken Calculator](https://leetcode.com/problems/broken-calculator/) | 1909 | work backwards: if target > start, target is odd → +1, even → ÷2 |
| [Movement of Robots](https://leetcode.com/problems/movement-of-robots/) | 1923 | collision = pass-through (positions stay sorted); sort initial positions, apply offset |
| [Maximum Number of Consecutive Values You Can Make](https://leetcode.com/problems/maximum-number-of-consecutive-values-you-can-make/) | 1931 | sort coins; if coin[i] > reach+1, stop; else reach += coin[i] |
| [Count Subarrays With Median K](https://leetcode.com/problems/count-subarrays-with-median-k/) | 1999 | encode: >k → +1, <k → −1; median is k iff prefix sum = 0 or 1 in subarray containing k |

**991 (Broken Calculator)** is the cleanest trick in the band: going forward is unclear (when to multiply, when to subtract), but backwards the greedy is obvious — if target is odd you must have subtracted last, if even you must have multiplied last. Going backwards you do the inverse operations (add 1 if odd, divide by 2 if even).

**2731 (Movement of Robots)** — the key physical insight is that two robots passing through each other is identical to them swapping identities. So you can pretend they pass through, track sorted positions, and just compute pairwise distances on the sorted array.

## GCD_LCM — 4 problems

GCD goes deep here — Bézout's identity and coprime selection via inclusion-exclusion.

| Problem | Rating | Angle |
|---------|--------|-------|
| [Minimum Number of Operations to Make All Array Elements Equal to 1](https://leetcode.com/problems/minimum-number-of-operations-to-make-all-array-elements-equal-to-1/) | 1929 | GCD of any subarray = 1 → find min-length subarray with GCD 1, then spread |
| [Minimum Length of Anagram Concatenation](https://leetcode.com/problems/minimum-length-of-anagram-concatenation/) | 1979 | valid period length divides n → check all divisors of n (smallest valid period = GCD-based) |
| [Count Ways to Choose Coprime Integers from Rows](https://leetcode.com/problems/count-ways-to-choose-coprime-integers-from-rows/) | 1982 | choose 1 from each row, GCD of all choices = 1 — Möbius inclusion-exclusion |
| [Check If It Is a Good Array](https://leetcode.com/problems/check-if-it-is-a-good-array/) | 1983 | can form 1 via linear combination iff GCD(all elements) = 1 — Bézout's identity |

**1250 (Check If It Is a Good Array)** — pure Bézout: given integers a₁, a₂, ..., aₙ, there exist integers c₁, ..., cₙ (positive or negative) such that `Σcᵢaᵢ = 1` if and only if GCD of all aᵢ = 1. Recognising this is the entire problem.

**3725 (Count Ways to Choose Coprime Integers)** — Möbius function approach: count(GCD=1) = Σ_{d=1}^{max} μ(d) × Π_{row} count(elements divisible by d in that row). The inclusion-exclusion runs over divisors d from 1 to max value.

## POWER — 3 problems

| Problem | Rating | Angle |
|---------|--------|-------|
| [Number of Squareful Arrays](https://leetcode.com/problems/number-of-squareful-arrays/) | 1932 | adjacent sums must be perfect squares — check via `sqrt` + verify |
| [Cycle Length Queries in a Tree](https://leetcode.com/problems/cycle-length-queries-in-a-tree/) | 1948 | complete binary tree: node at level = floor(log₂(node)), find LCA via dividing by 2 |
| [Minimum Non-Zero Product of the Array Elements](https://leetcode.com/problems/minimum-non-zero-product-of-the-array-elements/) | 1967 | key formula: (2^n−1) × (2^n−2)^(2^(n−1)−1) — fast exponentiation mod 1e9+7 |

**1969 (Minimum Non-Zero Product)** — the proof: in a range [1, 2^n−1], you can swap any bit between two numbers. To minimize product, make one number as large as possible (2^n−1) and all others as small as possible (pair up: one gets +1, one gets −1). The resulting product = (2^n−1) × (2^n−2)^(2^(n−1)−1). The exponent `2^(n-1)-1` itself requires fast exponentiation (it's ~10^14).

## Drill plan for this band

**Priority 1 — must be reflexive (high density + appears in every subsequent band):**
- **MOD_ARITH / prefix-sum mod**: 3381, 2435, 3202, 2872 (all 1900–1999 variants)
- **CONTRIBUTION (monotonic stack)**: 907 is canonical — if you can't derive it in 20 min, add it to zerotrac

**Priority 2 — high conceptual leverage:**
- **AP_SUM in binary search**: 1802, 2439, 2602 — the pattern is always "feasibility check uses sum formula"
- **BIT_OPS OR problems**: 2680, 2411, 3858 — all three use the same "per-bit last occurrence" idea
- **TRICK problems**: 991, 2731, 2488 — each requires a reframe before any algorithm makes sense

**Priority 3 — one-time but worth knowing:**
- CATALAN (1259) — know C(n) = (2n)!/(n!(n+1)!)
- Bézout (1250) — GCD=1 iff linear combination = 1
- Prime palindrome parity (866) — even-digit palindromes are always divisible by 11

**Skip for 1700 target:** MATRIX_EXP (only appeared at 1800–1899), PROB, STARS_BARS (not in this band). Focus time on MOD_ARITH + BIT_OPS + TRICK.
